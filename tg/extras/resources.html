Terragen™ plugins

Plugins can be used to expand the capabilities of Terragen.

Firmament ( Win ) - Firmament is a suite of Terrain Accessory plugins for import of many formats, including SDTS/DEM and BMP, into Terragen.

For Export Only ( Win / Mac ) - For Export Only is a suite of Terrain Accessory plugins which exports terrains in Windows BMP, Autodesk DXF, Wavefront OBJ and RenderMan RIB formats. For Export Only can also import Windows BMP files.

SOPack ( Win ) - SOPack contains a variety of plugins of different types, from water effects to surface map overlays, to terrain effects and to photo effects.

Solaris ( Win / Mac ) - Solaris is a Lighting Accessory plugin which calculates the position of the Sun according to a location on the Earth ( in latitude and longitude ), a date and a time of day.

WaterWorks ( Win / Mac ) - suite of Water Effect plugins, ranging from surf effects to ice and lava effects.

LensFX ( Win ) - plugin to mimic depth of field similar to a real camera.

HighDynamic ( Mac ) - HighDynamic is a Camera Effect plugin which generates HDRI images. It can output FP TIFF, Radiance .HDR and OpenEXR format images.

SOverlay ( Mac ) - SOverlay is a Surface Layer Effect plugin which lets you overlay an image on the terrain, or use an image to control surface layer distribution. It's based on the Image Overlay plugin from SOPack for Windows.

Integrate with other 3D applications

The following plugins and utilities help to integrate Terragen with other 3D applications.

LightWave 3D integration

TGtoLW ( Win ) - Freeware software which creates a complete Lightwave scene from a Terragen scene, including conversion of script files. Web page is in Italian.

3D Studio MAX integration

TG-Max ( Win ) - Mark Sporleder's TG-Max is a 3D Studio Max plugin with comprehensive Terragen scene integration capabilities. It facilitates animation/script generation, terrain import, HDR panorama generation, network rendering and more. There is a Lite version which is free for non commercial use as well as a more fully featured Pro version for commercial use.

Tomanek has written some utilities to integrate 3D Studio Max with Terragen. Unfortunately, we have not been able to test these utilities, but they are available for free download here.

Cinema 4D integration

Terra4D ( Win / Mac ) - Terra4D is a plugin for Cinema 4D which imports Terragen terrains, can export Terragen script files and more. The site is in German and English, and the plugin is in English.

Terragen Importer ( Win / Mac ) - Terragen Importer is a plugin for Cinema 4D which can import a variety of Terragen scene settings to make matching easier in Cinema 4D. It can also import Terragen script files.

TerraCin ( Win / Mac ) - TerraCin is a Cinema 4D plugin which can import Terragen terrains and other information to match scenes between the two applications. It can also read Terragen script files to match the camera and lighting.

Blender integration

Ter2Blend - Ter2Blend is a collection of scripts which help integrate Terragen with Blender, a powerful free modeller and renderer.

trueSpace integration

Urban Velkavrh has written a free trueSpace plugin which can write camera scripts and read and write Terragen terrain files.

3D Object Utilities

Deep Exploration ( Win ) - Deep Exploration is an easy-to-use 3D object converter - useful if you want to convert Lightwave Object files (exportable from Terragen) to other 3D formats for use in other rendering software.

3rd party applications

The following applications are written by 3rd parties and help to make Terragen features more accessible, such as the animation or script utilities, or are able to import and/or export Terragen files.

Animation/script utilities

Terranim ( Win ) - animation script generator by Daniel Parnham. This is the original Terragen animation utility that kick-started it all. A new version was recently released, which features ultra-smooth curves and a useful OpenGL real-time animation preview. As well as providing control over cloud and sun movement etc, Terranim can support custom animation commands. Whatever Terragen can animate, Terranim lets you control it.

Camera Path Editor ( Win ) - animation script generator by Sean O'Malley. Packed full of all sorts of goodies, including a 'Vehicle Cam', cloud and sun movement, handy 'global change' features and a FOV calculator, to name but a few.

Terragen Linear Camera/Target Movement Generator - a simple web-based utility to create simple Terragen scripts with individual camera/target control.

Terrain utilities

TerraConv ( Win ) - TerraConv is a freeware program for converting Terragen terrains into image file formats readable by image editing programs, and image files back into Terragen terrains. TerraConv supports 16 bit color depth, so you do not lose any altitude resolution in the process.

LandSerf ( Win / Mac ) - LandSerf is a freely available Java based GIS (Geographical Information System) application. It can import many common GIS file types ( including DEMs of various sorts ) and perform many GIS operations. Amongst other things, it can export Terragen terrain files.

3DEM ( Win ) - program for the display and manipulation of DEM files. It can export Terragen terrain files. The site also has a selection of links to DEM sources.

GeoFrac 2000 ( Win ) - GeoFrac 2000 is a terrain generation application with a range of capabilities, which is able to export Terragen terrain files.

Leveller ( Win ) - Heightfield editor/modeller/converter by Daylon Graphics. It can import and export Terragen terrain files.

Terrify & Terrain Browser ( Win ) - Terrify can be used to convert Terragen terrain files to RAW or Windows BMP formats. Terrain Browser displays a thumbnail view of Terragen terrain files. Visit the "Delphi Programs" page to download.

Wilbur ( Win ) - program for manipulating and converting heighfield data in a variety of formats including Terragen terrain.

TerraPainter ( Win ) - TerraPainter is a terrain editor which lets you create Terragen terrains by painting with a variety of brushes.

World Machine ( Win ) - World Machine is a terrain generator with quite a unique approach, you connect together various "building blocks" to generate the terrain. It has some excellent erosion filters which make for realistic terrains. It can save to several formats, including Terragen terrain files.

Landformer Pro ( Win ) - Landformer Pro is a standalone version of the terrain editor from Geomantics' Genesis II GIS program, and it uses Terragen's terrain file format as it's native format. It will be particularly useful to those wanting to use real world data and do things such as turning contour maps into Terragen terrains.

DEM2RWX ( Win ) - DEM2RWX can import Terragen terrain files and convert them into terrain objects which can be used with the Active Worlds 3D virtual reality/chat environment.

TerraMaker ( Win ) - TerraMaker is a terrain editor for Terragen terrains with a wide range of capabilities and interesting tools.

planetGenesis ( Win / Mac ) - planetGenesis is an opensource Java based planet and landscape generator. Amongst other formats, it can generate Terragen terrains at all sizes.

Miscellaneous utilities

TRaM (Terragen Render Task Manager) ( Win )
TRaM is a render task manager for Terragen. It controls Terragen running in the background and can be used to render a number of images or scripts without user intervention. It can optionally shut down your machine once all tasks are completed.

TerraSky (temporarily offline) ( Win ) - TerraSky is a utility for making skyboxes from Terragen images for the Quake 3 and Return to Castle Wolfenstein games. It includes a script to render the required images and a utility which converts the images so they can be used in the game.

DigArts Software ( Win / Mac )
Terragen does not currently support vegetation , but one way of adding it to your scenes would be to use the variety of tree and foliage painting tools offered by DigArts Software, which work in conjunction with Painter, Paint Shop Pro, Photo Paint and Photoshop.

Photorealistic Mountain View ( Win )
Allen Fu has written a terrain rendering demo based on image based rendering techniques that lets you fly around a Terragen terrain in realtime. You can see an image from the demo at the above link, along with more information. The authoring tool is available upon request.

Community

Terragen has a strong user community, which you are more than welcome to take part in.

Mailing lists

This is a listing of the main mailing lists related to Terragen, though it's by no means exhaustive. Please note that none of these mailing lists are run by Planetside.

terragen - This is the main Terragen mailing list. It's a very civilised mailing list by internet standards, and everyone is welcome.

TerragenMac - This is the main mailing list for Terragen Mac, and is for discussion of things related to the Mac version. We strongly suggest you also join the main Terragen list, mentioned above, because there will be general discussion there which will be of benefit to you whichever platform you use Terragen on.

terragenfriends - The terragenfriends mailing list is the place for off-topic posts and comments by Terragen users.

terranimation - The terranimation list is for discussing the animation capabilities of Terragen.

TerragenTerrains - This group is aimed at distributing terrains that Terragen users might be interested in, many generated from real world DEMs.

TerragenGalleries - This list is for posting announcements about new Terragen galleries and updates to existing ones.

TerragenPLUSPost - This list is for talking about enhancing Terragen images using other programs and use Terragen images in conjuction with other programs.

Contests

A number of Terragen contests are run, most on a monthly basis. Most of the contests maintain archives, and it's well worth browsing through them to get an idea of the range and ability of Terragen and it's users. There are some spectacular images from past contests.

TERRA-Worlds - TERRA-Worlds is a monthly contest.

Ashundar - Ashundar runs a monthly Terragen contest.

Renderosity Terragen forum - The Terragen forum at Renderosity has a themed monthly challenge competition. You need to register with Renderosity ( free ) to view the forum.

TerragenPLUSPost - The TerragenPLUSPost competition allows and encourages postprocessing of Terragen images.

The Advanced Terragen Contest - As a number of people have been using Terragen for several years, the Advanced Terragen Contest aims to set specific challenges for advanced users.

Other resources

Websites

These websites have good listings of Terragen and related resources, such as tutorials, links to real world terrain resources and the like.

TerraSource - TerraSource has an extensive listing of tutorials, applications, real world terrain data sources, user galleries and much more. Well worth a visit.

TerraNet - although not as current as TerraSource, TerraNet has an extensive listing of galleries, as well as other resources.

Terrain resources

You may find some of the following links useful if you want to use external data within Terragen. Remember, Terragen can import raw binary data as terrain. Most paint programs can export images in raw format.

Space Graphics - Space Graphics features a number of resources related to Earth and Mars, including free Terragen terrain files. There's a lot of other nice looking resources for those interested in both planets, with some especially interesting items regarding Mars.

DEM2TGA - small utility for converting USGS DEM files to TGA images.

TopoWeb - useful resource.

TopoWeb DEM Tutorial - how to use real world elevation maps in programs such as Terragen.
